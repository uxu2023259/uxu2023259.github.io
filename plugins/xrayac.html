XRayAC 生存反作弊 · 项目介绍

XRayAC 为 Paper 生存服提供事件驱动的反作弊检查，覆盖移动、战斗、快速破坏、Nuker 与矿物统计等场景。默认运行在观察模式，管理员可先收集证据，再按服务器实际情况配置告警或踢出。

插件介绍

检查移动、战斗和采矿行为，默认观察模式，可逐步启用提醒或踢出。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

多类行为检查

覆盖移动、战斗数据包、破坏速度与集中挖掘等行为。

证据与调查

可查看最近告警、检查玩家记录和运行健康状态。

分级处理

支持 observe、alert、kick 模式，默认 observe。

低风险矿物统计

矿物统计用于管理员观察，不计入处罚分数，也不触发踢出。

异常自动降级

低 TPS、无效配置或 PacketEvents 不可用时回到观察模式。

使用流程

一

先以观察模式收集服务器行为证据。

二

检查 /xrayac alerts 与玩家记录，调整世界和插件白名单。

三

确认误报可控后，再逐步启用提醒或踢出。

运行信息

支持平台

Paper 1.21.11；Java 21。

依赖组件

PacketEvents 2.x 用于数据包战斗样本；缺失时其他检查仍可工作。

管理命令

/xrayac alerts、inspect、mode、exempt、health、reload。

矿物统计只用于观察。项目没有自动封禁；启用自动踢出前请先收集证据并按服务器环境调优。 打开 GitHub 项目
