封禁名牌

把 LiteBans 历史整理为可查询的玩家标记

封禁记录 · 玩家榜单 · 头顶与 Tab 标记

封禁名牌 · 项目介绍

封禁名牌从 LiteBans 读取玩家封禁历史，整理为可检索的记录和榜单，并可将简短标记显示在玩家名牌或 Tab 名称前。插件提供中文管理界面，便于查看同步状态和记录来源。

插件介绍

同步 LiteBans 封禁历史，提供玩家查询、榜单与罪恶标记展示。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

封禁记录同步

读取 LiteBans 历史并按计划更新玩家聚合记录。

榜单与查询

通过命令查看榜单、玩家记录或打开界面。

名牌标记

按配置在玩家头顶与 Tab 前缀显示简短标识。

多种存储方式

支持 H2、MariaDB 与 MySQL 配置；可通过导出文件减少 H2 文件锁冲突。

同步诊断

管理员可查看同步来源、失败原因和有效记录数。

使用流程

一

配置 LiteBans 数据库或导出文件位置。

二

插件按启动延迟与同步间隔更新历史数据。

三

玩家查询记录或查看榜单，名牌显示相应标记。

运行信息

支持平台

Paper 1.20.4–1.21.11。

依赖组件

LiteBans 与适配当前服务端版本的 ProtocolLib。

管理命令

/bantag 榜单、界面、查询、同步、状态、重载。

数据库文件正在被 LiteBans 使用时，优先配置 BanTag 导出文件，避免直接读取被锁定的 H2 数据库。 打开 GitHub 项目
