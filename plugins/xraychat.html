XRayChat 全服聊天 · 项目介绍

XRayChat 将多服聊天与管理能力集中在群组服务器中：中心端统一路由和 SQLite 状态，Paper 子服安装 Agent 与 PacketEvents。项目整合聊天、私聊、审核、喇叭广播、文字采集与网页管理。

查看核心能力查看 GitHub 仓库

插件介绍

为群组服提供聊天路由、私聊、审核、广播和网页管理能力。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

跨服聊天路由

让多个 Paper 子服通过中心端共享聊天消息。

私聊与审核

支持玩家私聊和消息审核能力。

广播与文字采集

提供喇叭展示和文字采集相关功能。

网页管理

包含配套网页管理与 Agent 协议。

集中状态存储

中心端使用 SQLite 保存运行状态。

使用流程

一

在代理中心部署 Hub，并为 Paper 子服安装 Agent。

二

配置 PacketEvents、中心连接与消息策略。

三

通过游戏内命令和网页端管理跨服聊天。

运行信息

运行环境

Java 21；群组代理中心与 Paper 子服。

依赖组件

Paper 子服安装 XRayChat 与 PacketEvents；按部署说明配置代理端。

构建部署

项目提供 build.ps1、部署、备份恢复与验收说明。

这是由中心端与子服 Agent 组成的平台项目，不是单个 Paper JAR。部署、备份与升级请按仓库文档执行。 打开 GitHub 项目
