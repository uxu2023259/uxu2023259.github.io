明商店 · 项目介绍

明商店是面向 Paper 服务器的中文 GUI 商店插件。玩家通过 /ming_shop 打开商店界面，管理员根据插件配置维护商品与价格；项目支持 Vault 经济，并可选适配 Geyser 玩家。

查看核心能力查看 GitHub 仓库

插件介绍

提供中文图形商店界面，支持 Vault 经济并可选接入 Geyser。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

中文商店界面

玩家通过图形界面浏览并购买商品。

经济系统接入

依赖 Vault 与服务器经济提供方完成交易。

跨平台适配

可选接入 Geyser-Spigot，面向基岩版玩家调整体验。

命令帮助

提供商店入口与帮助命令。

使用流程

一

安装 Vault 和经济提供方，按需安装 Geyser。

二

按项目配置设置商品、价格及界面内容。

三

玩家使用 /ming_shop 打开商店并完成交易。

运行信息

支持平台

Paper 1.21.11。

依赖组件

Vault；Geyser-Spigot 为可选依赖。

玩家命令

/ming_shop 打开商店；/ming_shop help 查看帮助。

交易依赖服务器经济插件。正式开放前请检查商品价格、库存和经济余额变化。 打开 GitHub 项目
