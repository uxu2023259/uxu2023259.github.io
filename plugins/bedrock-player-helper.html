基岩玩家助手 · 项目介绍

基岩玩家助手为跨平台服务器补齐基岩端常用交互。它提供传送请求、返回位置、私聊和表单操作，并能通过配置单独启停功能，控制请求时限和表单队列。

查看核心能力查看 GitHub 仓库

插件介绍

面向基岩版玩家提供传送请求、返回和私聊表单，并支持按功能开关。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

传送请求

支持请求传送到玩家或邀请玩家传送过来，并可接受或拒绝。

返回位置

提供 /back 返回上一个记录位置。

基岩版表单

将部分操作放入更适合基岩触屏端的表单界面。

私聊支持

提供玩家私聊功能和基岩版表单交互。

可配置开关

可单独启用传送请求、返回和私聊，并调整请求超时与冷却。

使用流程

一

基岩版玩家通过命令或表单发起请求。

二

目标玩家接受或拒绝，插件执行对应传送。

三

需要时使用返回功能回到之前的位置。

运行信息

支持平台

Paper 1.21；基岩版识别通过 Floodgate。

常用命令

/tpa、/tpahere、/tpaccept、/tpdeny、/back。

部署要求

跨平台识别需要安装 Floodgate，并在服务器启用相应功能。

部分功能只针对基岩版玩家呈现表单。服务器仍需正确配置 Geyser 与 Floodgate 跨平台连接。 打开 GitHub 项目
