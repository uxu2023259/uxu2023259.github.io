生态方块

把挖矿与击杀行为转化为可配置的经济奖励

挖矿奖励 · 击杀奖励 · Vault 经济

生态方块 · 项目介绍

生态方块将日常生存行为接入服务器经济：玩家挖掘配置中的矿石或击杀生物后，插件通过经济接口发放奖励，并可在聊天反馈奖励结果。管理员可以调整奖励、游戏模式和反馈开关。

查看核心能力查看 GitHub 仓库

插件介绍

玩家挖掘矿石或击杀生物时发放金币，并可配置奖励和反馈方式。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

挖矿奖励

按矿石种类配置奖励金额和中文名称。

击杀奖励

为击杀生物配置金币奖励。

经济插件接入

通过 Vault 对接服务器当前经济提供方。

适用模式控制

可选择允许发奖的游戏模式，并分别控制挖矿和击杀功能。

状态与重载

提供奖励配置状态查看和热重载命令。

使用流程

一

安装 Vault 以及兼容的经济提供插件。

二

在配置中设置矿石、生物奖励与适用模式。

三

玩家挖矿或击杀生物后自动获得金币。

运行信息

支持平台

Paper 1.21。

依赖组件

Vault 与可用的经济提供方。

管理命令

/ecoblock status、/ecoblock reload。

默认奖励仅适用于配置允许的游戏模式。上线前建议先校准奖励数值，避免影响服务器经济平衡。 打开 GitHub 项目
