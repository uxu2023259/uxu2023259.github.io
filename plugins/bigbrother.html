BigBrother Java 版接入

让 Java 版 1.8 客户端接入 PocketMine 服务端

Java 协议 47 · TCP 监听 · PocketMine/InCore

BigBrother Java 版接入 · 项目介绍

BigBrother 是面向 PocketMine/InCore 的协议桥接插件。它监听独立 TCP 端口，把支持的 Java 版 1.8 数据包转换为核心服务端能够处理的玩家数据包，让旧版 Java 客户端连接到 Bedrock 服务端。

查看核心能力查看 GitHub 仓库

插件介绍

在 PocketMine/InCore 上转换 Java 1.8 客户端协议，接入服务端玩家数据包模型。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

Java 1.8 协议接入

支持协议 47 客户端连接到 PocketMine/InCore。

数据包转换

在 Java 客户端与核心玩家数据包模型之间转换受支持的数据包。

独立 TCP 监听

监听单独配置的 TCP 地址和端口，与 Bedrock 的 RakNet UDP 端口分开。

在线身份验证

可通过 Mojang 会话服务验证 Java 玩家；公开服务器建议保持在线验证。

使用流程

一

将 PHAR 安装到 PocketMine/InCore 的 plugins 目录。

二

配置 TCP 监听地址、端口与在线身份验证选项。

三

Java 1.8 客户端连接桥接端口；Bedrock 客户端继续使用原服务器端口。

运行信息

支持平台

PocketMine/InCore；Java 8 客户端协议 47。

运行依赖

PHP 8 CLI 构建，运行依赖按仓库和服务端要求配置。

网络配置

需开放单独 TCP 端口；在线验证需要 OpenSSL、cURL 与 HTTPS 出站连接。

这是 PocketMine 生态插件，不是 Paper 插件。在线验证建议保持开启；不要在公网服务器使用未经验证的离线名称。 打开 GitHub 项目
