AI 聊天 · 项目介绍

AI 聊天插件把模型问答接入服务器聊天，玩家可使用 /ai 提交问题。管理员可以配置服务商、默认模型、上下文轮数、输出上限、冷却和并发，并通过权限档位控制玩家可选模型。

插件介绍

通过游戏内命令向 DeepSeek 或 OpenAI 兼容接口提问，并可按权限开放模型。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

多服务商

配置 DeepSeek 和 OpenAI 兼容接口，并选择可用模型。

游戏内提问

玩家通过 /ai 发送内容，回答回到游戏聊天。

模型权限

按权限档位开放不同模型，玩家权限可组合。

请求限制

支持玩家冷却、全局并发限制、上下文轮数和输出长度上限。

可扩展接入

可与 PlayerChat 等聊天插件协作。

使用流程

一

管理员配置服务商接口和 API 密钥。

二

为玩家授予可用模型档位权限。

三

玩家使用 /ai 提问，插件返回模型回答。

运行信息

支持平台

Paper 1.20 或更高版本。

使用命令

/ai <内容>；模型访问按配置权限控制。

运行要求

使用前需为启用的模型服务商配置有效 API 密钥。

API 密钥通过服务器配置提供。请限制配置文件访问权限，并按服务商的费用和速率限制进行配置。 打开 GitHub 项目
