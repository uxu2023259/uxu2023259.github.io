航点数据包修复 · 项目介绍

航点数据包修复用于处理 Paper 后端发送异常航点更新包导致客户端断开的问题。插件登记航点新增信息，只允许已登记航点的更新通过，并在玩家离开或重生等时机清理跟踪状态。

查看核心能力查看 GitHub 仓库

插件介绍

过滤异常的航点更新数据包，降低客户端因非法更新包断开的情况。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

航点登记

新增航点包会登记航点标识并正常发送。

异常更新拦截

缺少对应新增记录的更新包会被拦截。

标识兼容

航点标识支持 UUID 与字符串。

状态清理

玩家加入、重生、退出或被踢时清理对应记录。

可选诊断日志

可开启拦截日志，并按玩家和异常类型限频。

使用流程

一

安装 PacketEvents 与 WayFix 到 Paper 后端。

二

插件跟踪新增和删除航点包。

三

仅转发已登记航点的更新，过滤异常更新。

运行信息

支持平台

Paper 1.21.11 后端。

依赖组件

PacketEvents 2.13.0。

部署位置

仅安装在 Paper 后端，不安装在代理端。

插件处理的是 Paper 发往客户端的航点数据包。请确保 PacketEvents 版本符合项目说明。 打开 GitHub 项目
