XRayMC 服务器管理 · 项目介绍

XRayMC 服务器管理插件面向 Paper 1.21.11，集合玩家物品快照保护、管理员 OP 验证、维护模式和特殊装备管理。快照读取失败时可阻止玩家登录，并按每 Tick 限额分摊采集以降低高峰开销。

插件介绍

提供物品快照恢复、OP 验证名单、维护白名单和特殊装备管理。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

物品快照

保存、查询、恢复或删除玩家物品快照，数据使用 SQLite。

OP 验证

管理受信任管理员名单，并在启动时恢复登记的 OP。

维护模式

开启维护时仅允许白名单与已验证管理员进入。

特殊装备管理

发放特殊装备并通过 GUI 定位或销毁装备实例。

命令管控

按规则隐藏或阻止插件查询和诊断命令。

使用流程

一

配置数据库、权限与维护白名单。

二

使用 /xraymc snapshot 与 operator 命令管理玩家和管理员保护。

三

维护时启用白名单，结束后关闭维护并检查状态。

运行信息

支持平台

Paper 1.21.11。

管理命令

/xraymc snapshot、operator、whitelist、maintenance、equipment、reload。

权限

管理权限默认关闭，使用前为可信管理员授予 xraymc.admin 或细分权限。

首次部署前请登记管理员或维护白名单，避免开启维护模式后将管理人员挡在服务器外。 打开 GitHub 项目
