Geyser 组件更新 · 项目介绍

Geyser 组件更新可部署在 Paper 或 BungeeCord/Waterfall 服务端，按平台检查相应的 Geyser 与 Floodgate 文件，并可覆盖 Via 系列组件。管理员能手动检查、查看状态和重载配置。

插件介绍

自动检查 Geyser、Floodgate 和 Via 组件更新，并准备下载与替换流程。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

识别运行平台

按 Paper 或代理端使用对应组件文件和更新流程。

组件覆盖

可检查 Geyser、Floodgate，以及配置中的 Via 系列或 SkinsRestorer。

启动检查与定时计划

支持启动时检查，也可配置每日检查时间。

下载与文件校验

检测到新构建后下载文件并准备离线替换。

状态可查看

提供检查、状态与配置重载命令。

使用流程

一

插件按平台检查已安装组件版本。

二

发现更新后下载文件并校验，准备替换。

三

计划更新会按配置安排服务端关闭，以便下次启动加载新文件。

运行信息

支持平台

Paper 与 BungeeCord/Waterfall；对应文件以配置为准。

管理命令

/geyserupdate check、/geyserupdate status、/geyserupdate reload。

维护注意

每日定时更新在下载完成后可能执行服务端关闭命令；请配置维护时间。

更新组件会改变服务器文件，并可能按配置停服。请先备份相关 JAR，并核对每日计划与关闭命令。 打开 GitHub 项目
