原版指令修复 · 项目介绍

原版指令修复针对 Paper 环境下与原版不同或被插件覆盖的常用指令处理方式，恢复 give、kill 和 tp 的原版使用语义，并兼容项目支持的 Paper 版本范围。

查看核心能力查看 GitHub 仓库

插件介绍

在 Paper 1.20.4–1.21.11 上恢复原版 give、kill、tp 指令的使用体验。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

give 指令

修复物品给予指令的原版行为。

kill 指令

恢复目标实体或玩家的原版清除语义。

tp 指令

修复玩家与实体传送指令的兼容行为。

版本覆盖

README 声明兼容 Paper 1.20.4 至 1.21.11。

使用流程

一

安装插件并重启 Paper 服务端。

二

通过服务器原有方式使用 give、kill 或 tp。

三

在实际玩法环境中确认指令与其他插件的兼容情况。

运行信息

支持平台

Paper 1.20.4–1.21.11。

指令范围

give、kill、tp。

项目名称

插件元数据名称为 CommandFix。

指令行为可能受其他命令插件影响。若存在重名命令，请检查服务端命令优先级和插件配置。 打开 GitHub 项目
