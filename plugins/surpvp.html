SurPVP 竞技场 · 项目介绍

SurPVP 为 Leaf 服务端提供隔离式竞技场。玩家可排队进行 1v1 或 2v2 对战，插件管理竞技模式、地图分配与排名，并通过事务式玩家状态恢复尽量确保对局结束后玩家状态回到进入竞技前。

插件介绍

提供隔离竞技场、1v1/2v2 匹配、套装与长期排名，并支持战后状态恢复。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

隔离式竞技场

使用分配的竞技场空间运行对局，减少对生存世界的干扰。

多种对局模式

支持 1v1 与 2v2 匹配及队伍管理。

套装与排行榜

管理竞技套装、永久排名和玩家统计。

玩家状态恢复

保存并恢复对局前状态，支持异常恢复管理。

扩展集成

可选接入 mcMMO、PlaceholderAPI 与 GSit。

使用流程

一

玩家通过 /pvp 开启状态并加入匹配队列。

二

系统分配竞技场与模式，开始隔离对局。

三

对局结束后结算排名并恢复玩家状态。

运行信息

支持平台

Leaf 1.21.11；Java 21。

依赖组件

Multiverse-Core；mcMMO、PlaceholderAPI、GSit 为可选集成。

命令入口

玩家使用 /pvp，管理员使用 /pvpadmin。

竞技场需按项目文档配置并验证地图、出生点和恢复流程。建议在维护窗口完成首次配置。 打开 GitHub 项目
