停服预警 · 项目介绍

停服预警在服务器进入正常关闭流程前向在线玩家发布倒计时，结合聊天消息与 BossBar 展示，让玩家及时完成整理、保存和下线准备。

插件介绍

在服务器正常关闭前显示聊天和 BossBar 倒计时提醒。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

关闭前提醒

正常停服前按配置展示倒计时通知。

多渠道提示

同时使用聊天信息和 BossBar 显示剩余时间。

适合维护窗口

可配合计划维护或管理指令，让玩家提前知晓停服安排。

轻量运行

围绕服务器关闭事件执行提示，无需额外玩家命令。

使用流程

一

服务端进入正常关闭流程。

二

插件向在线玩家显示聊天与 BossBar 倒计时。

三

倒计时结束后由服务端继续执行关闭流程。

运行信息

支持平台

Paper 1.21。

运行方式

由服务器正常关闭流程触发。

配置说明

倒计时与提示文案按仓库配置文件调整。

此插件面向正常关闭流程。强制终止进程或系统崩溃时，服务器无法保证发送玩家通知。 打开 GitHub 项目
