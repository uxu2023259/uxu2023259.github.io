TNT 放置审计 · 项目介绍

TNT 放置审计面向生存服管理，记录危险爆炸物相关放置行为，并让管理员按玩家、类型或分页查询记录。插件可按配置反馈通知，便于追查可能造成破坏的行为。

插件介绍

审计生存服危险爆炸物放置记录，支持查询、通知和管理查看。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

放置行为记录

记录被纳入规则的危险爆炸物放置事件。

记录浏览

支持分页或按玩家筛选的管理查看界面。

分类查询

可根据记录类型筛选审计结果。

配置热重载

支持重载检测、通知和记录相关设置。

使用流程

一

管理员配置需要审计的行为与通知方式。

二

玩家放置符合规则的爆炸物时生成记录。

三

通过管理命令查看、筛选和追踪相关事件。

运行信息

支持平台

Paper 1.20 或更高版本。

管理命令

/tntprotect help、/tntprotect list、/tntprotect reload。

适用场景

需要追踪危险爆炸物使用情况的生存服务器。

该插件用于审计和通知，不替代领地、权限或爆炸保护插件的实际防护配置。 打开 GitHub 项目
