XrayDP 数据包插件 · 项目介绍

XrayDP 是 Paper 插件与 IN0THN 数据包的组合项目。构建时将数据包打入插件 JAR，启动时负责部署并检查每个世界的数据包文件；高频玩法由插件事件和状态跟踪处理，避免每 Tick 扫描全部实体。

查看核心能力查看 GitHub 仓库

插件介绍

将配套数据包打入插件，并用服务端事件处理物品和玩家状态逻辑。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

内置数据包

数据包随插件发布，启动时写入各世界 datapacks 目录并检查文件完整性。

事件驱动逻辑

物品使用、强化生物和玩家状态等功能由插件事件与状态跟踪处理。

定向实体查询

只跟踪相关实体或使用局部空间查询，避免全量实体轮询。

配套命令

支持发放、召唤配套物品，以及重载数据包内容。

使用流程

一

将插件安装到 Paper 服务器并启动。

二

插件部署内置数据包，随后执行一次数据包重载。

三

使用项目命令发放或召唤配套物品与生物。

运行信息

支持平台

Paper 1.21；Java 21；Maven 3.9 或更高版本构建。

管理命令

/awa.uxu.xraydp give、/awa.uxu.xraydp summon、/xraydpreload。

部署要点

启动时会替换包含 in0thn 命名空间的数据包，请按仓库说明检查现有数据包。

这是与配套数据包共同工作的玩法项目。更新前请备份世界数据，并按仓库的安装步骤执行数据包重载。 打开 GitHub 项目
