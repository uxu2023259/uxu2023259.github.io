命令遮蔽 · 项目介绍

命令遮蔽允许管理员配置需要隐藏或限制的命令根，可选择仅隐藏补全、仅阻止执行或同时处理。规则兼顾 Bukkit、Minecraft 和 Paper 命名空间形式，并提供受信任玩家白名单。

查看核心能力查看 GitHub 仓库

插件介绍

按规则隐藏命令补全或阻止命令执行，降低普通玩家查询管理入口的能力。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

多种规则模式

支持 HIDE、BLOCK、BLOCK_AND_HIDE 三种命令控制策略。

命名空间覆盖

可同时配置普通命令名和 bukkit:、minecraft:、paper: 等形式。

白名单放行

通过玩家白名单为可信用户保留正常访问。

在线即时应用

重载配置后刷新在线玩家命令树。

控制台管理

提供配置重载命令。

使用流程

一

在配置中加入要隐藏或阻止的命令根。

二

选择命令补全和执行拦截模式。

三

使用控制台重载配置并检查在线玩家命令树。

运行信息

支持平台

Paper 1.21。

管理命令

/cmdmask reload；仅控制台或 RCON 可执行。

安全提示

离线模式下按玩家名放行可能被冒用，只填写可信名单。

命令遮蔽属于访问界面控制，不替代服务端权限配置；仍应为敏感命令设置正确权限。 打开 GitHub 项目
