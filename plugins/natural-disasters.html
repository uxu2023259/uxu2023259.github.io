自然灾害 · 项目介绍

自然灾害面向 Leaf 生存服，只在主世界运行。插件会按配置随机安排灾害，在正式开始前显示倒计时；管理员可指定灾害、查看状态或停止事件，基岩版管理员还可以使用表单操作。

插件介绍

在主世界随机触发箭雨、火灾等灾害，并通过聊天和 BossBar 提前预警。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

多种灾害

包含箭雨、浴火焚烧、箭毒蛙浪潮与血红坟墓等事件。

提前预警

通过聊天提示和 BossBar 倒计时，为玩家提供寻找掩体或准备装备的时间。

差异化效果

灾害分别使用箭矢、燃烧、毒蛙与视觉状态效果，适配 Java 与 Geyser 基岩玩家。

自动清理

灾害结束、玩家离开或插件卸载时清理相关 BossBar、实体和效果。

管理表单

基岩版管理员可打开表单开始、停止灾害、查看状态和重载配置。

使用流程

一

按设定间隔抽取灾害并公布预警。

二

倒计时结束后触发灾害并显示当前进度。

三

灾害结束后移除临时实体和状态效果。

运行信息

支持平台

Leaf 1.21.4；Java 21。

管理命令

/nd 开始、/nd 停止、/nd 状态、/nd 重载；权限 naturaldisasters.admin。

兼容说明

红色雾效支持 Geyser 基岩玩家；未安装 Geyser 时插件仍可运行。

默认配置按主世界运行，并包含随机触发间隔与预警时长；可先在测试世界调整灾害强度。 打开 GitHub 项目
