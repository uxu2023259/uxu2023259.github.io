药水融合

在铁砧中合成保留多种效果的药水

铁砧合成 · 效果合并 · 多种药水形态

药水融合 · 项目介绍

药水融合把药水组合放进原版铁砧流程：相同类型的两瓶药水可以合成一瓶，同时保留两边的效果。结果颜色按输入药水显示颜色混合，尽量只响应明确的药水合成操作。

查看核心能力查看 GitHub 仓库

插件介绍

将两瓶同类型药水放入铁砧，合并效果并按实际颜色生成混合药水。 项目源码、更新记录及安装细节请查看 GitHub 仓库。

核心能力

铁砧操作

使用玩家熟悉的铁砧界面完成药水合成。

效果保留

不同效果全部保留；重复效果按等级与持续时间合并。

支持多种药水

支持普通、喷溅和滞留药水的混合。

兼顾原版流程

不取消铁砧事件，减少对其他铁砧操作和插件的影响。

使用流程

一

将两瓶相同类型的药水放入铁砧。

二

检查预览结果中的合并效果与药水形态。

三

取出融合药水，按合并后的效果使用。

运行信息

支持平台

Paper 1.20.4–1.21.11；Java 17 或更高版本。

操作方式

无需额外命令，通过铁砧交互使用。

项目产物

源码仓库提供 Maven 构建说明与 PLUGIN 目录成品。
